# 短视频脚本切片机 · 部署与说明

零代码 AI Web 工具，把长文 / 直播录音文字一键拆成 10 条可拍爆款短视频脚本。单文件、零依赖、可部署魔搭创空间。

## 功能清单（8 大模块）

1. **智能观点萃取**：切句 → 爆款潜力评分 → 按分排序，附推荐理由。
2. **多版本脚本生成**：每条观点生成 痛点型 / 反转型 / 干货型 三种结构。
3. **黄金3秒钩子库**：每条脚本 5 种开场（疑问 / 数字 / 冲突 / 共鸣 / 悬念），可自由复制替换。
4. **画面分镜建议**：场景 / 人物动作 / 字幕重点 / 特效建议，可直接交付拍摄团队。
5. **BGM 风格匹配**：按情绪基调（励志 / 治愈 / 紧张 / 幽默）推荐 3-5 首风格 + 节奏点。
6. **热点关键词嫁接**：将通用词替换为近期热梗表述，提升算法命中率（强度可调）。
7. **脚本日历排期**：按脚本数量自动生成 7 天发布排期，标注最佳时段与平台适配。
8. **爆款标题生成器**：每条脚本 10 个标题，覆盖 悬念 / 数字 / 对比 / 情感 四类模板。

## 文件说明

- `index.html` —— 工具本体（单文件，含全部逻辑与样式，无需任何构建）。
- 无需安装依赖、无需后端，双击即可在浏览器打开使用。

## 部署到魔搭创空间（零代码）

### 方式一：前端应用空间（推荐，最省事）
1. 登录 魔搭社区 → 进入「创空间 / Studio」。
2. 创建新空间，运行时/模板选择 **「前端应用」** 或 **「静态网页 / HTML」** 类型（不同版本入口名称可能略有差异）。
3. 上传本目录下的 `index.html`（作为首页入口文件）。
4. 等待构建完成，即可获得可分享的公开访问地址。

> 因为 `index.html` 是纯静态单文件，不依赖任何服务端与构建流程，天然适配「零代码」部署。

### 方式二：任意静态托管（备选）
可直接托管到 GitHub Pages、Vercel、Netlify 等，上传 `index.html` 即可。

### 方式三：Gradio SDK 空间（仅当创空间只提供 Gradio/Streamlit 时）
若你的空间只支持 Gradio SDK，可用仓库内的 `app.py` + `requirements.txt` 作为入口：
- 将 `index.html` 与 `app.py`、`requirements.txt` 一同提交到空间仓库；
- `app.py` 通过 Gradio 挂载并展示该 HTML 页面。
- 注意：部分 Gradio 版本会对 `gr.HTML` 中的 `<script>` 做清洗，若出现脚本不执行，请改用「方式一/二」的纯静态托管。

## 使用方式

1. 在「内容输入」框粘贴长文 / 直播逐字稿，或点「载入示例内容」体验。
2. 选择发布平台、情绪基调、热点嫁接强度、生成观点数。
3. 点「开始切片，生成 10 条脚本」。
4. 展开每个观点查看脚本、钩子、分镜、BGM、嫁接结果；底部可一键导出 Markdown / JSON / 纯文本，或复制全部。

## AI 增强（可选）

默认使用内置「规则 + 模板」智能引擎，离线即可产出可用脚本。如需更强创意，可在「AI 增强模式」中填入兼容 OpenAI / 魔搭的 API 地址、Key 与模型名进行增强。
## 说明

- 内置引擎用于快速产出「可拍脚本草稿」，建议人工二次润色。
- 热点词库为示例性映射，可按行业自行扩展 `HOTWORDS` 常量。
